# Магазин техники DNS

Практическая работа №2 (вариант 7).

## Описание проекта

Адаптивная веб-страница магазина современной техники с каталогом товаров, таблицей цен и навигацией.

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, медиазапросы)
- Адаптивный дизайн (мобильные устройства, планшеты, десктоп)

## Функциональность

- Навигационное меню с якорными ссылками
- Каталог товаров в виде карточек (Grid)
- Таблица прайс-листа
- Адаптивная верстка (4 → 2 → 1 колонка)
- Внешняя ссылка на ресурс

## Как открыть

1. Скачайте репозиторий
2. Откройте файл `pr2.html` в браузере
